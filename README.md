# VERDANT v0.1.10005

Воксельная песочница на Three.js/WebGPU. Мир 2×2 км, глубина до −1000 м.

## Где скачать

Установщик Windows (**VERDANT-Setup-0.1.10005.exe**) будет доступен в [GitHub Releases](https://github.com/Dmitrynest2012/VERDANT/releases) **только после успешной сборки Windows в GitHub Actions**. Просто наличие коммита исходников не означает, что установщик опубликован.

Для разработческого запуска из исходников (в VS Code): Node.js 22.12+, `npm install`, `npm run dev` — Vite и Electron в отдельном окне, F12 открывает DevTools отдельно. `npm run dev:browser` сохраняет прежний запуск через браузер.

## Обновления

- Установленный `.exe`: проверка [GitHub Releases](https://github.com/Dmitrynest2012/VERDANT/releases), загрузка через electron-updater, установка после предложения перезапустить приложение.
- VS Code `npm run dev`: проверка пары архива PROJECT + TEXTURES_1K каждые 5 минут. Проверки SHA-256, резервная копия и откат.
- Впервые GitHub обновления работают только **после публикации первого релиза**; сохранения из браузера не мигрируют в Electron автоматически, это разные профили браузера.
- Раздельные архивы исходников и 1K-текстур сохраняются по правилам проекта. Пользовательские MP3, мир и настройки удалять запрещено.

## Управление

WASD — движение, Shift — бег, Space — прыжок, E — инвентарь, F — фонарик, M — карта, N — музыка, F12 — отдельное окно разработчика (в Electron).

Карта: четыре масштаба 200/400/800/1600 м; закрытие по M/Esc не вызывает паузу.

## Музыка

Положить `relax.mp3` в `public/audio/` в VS Code. В установленном приложении музыка требует отдельной пользовательской установки/порта контента и не включается в поставку.
