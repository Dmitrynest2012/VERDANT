# VERDANT v0.1.10006

Воксельная песочница на Three.js/WebGPU и Electron. Мир 2×2 км, глубина до −1000 м.

## Обновление установленной игры — через GitHub

Основной канал: [GitHub Releases](https://github.com/Dmitrynest2012/VERDANT/releases).
Запущенный установленный VERDANT проверяет новые версии через 9 секунд после старта и затем каждые 30 минут. При доступном интернете новая версия скачивается автоматически. После загрузки появляется окно с кнопками «Позже» и «Перезапустить». Перезапуск выполняется только после подтверждения пользователя.

Ручное скачивание ZIP, `npm install`, VS Code и повторный запуск установщика не нужны для обычного обновления уже установленного приложения. ZIP исходников и PNG остаются резервным способом и вариантом для разработки.

**Релиз готов для приложения только после успешной публикации EXE, latest.yml и blockmap.** ZIP в чате или коммит на main не являются доставкой обновления. Порядок выпуска: [RELEASE_DELIVERY.md](docs/RELEASE_DELIVERY.md).

## Разработка

Node.js 22.12+, `npm install`, `npm run dev` запускают Vite и Electron. F12 открывает DevTools отдельно. `npm run dev:browser` сохраняет браузерный режим. `npm run update:status` — диагностика обновлятора исходников.

## Управление

WASD — движение, Shift — бег, Space — прыжок, E — инвентарь, F — фонарик, M — карта, N — музыка, F12 — инструменты разработчика.
Карта: 200/400/800/1600 м; закрытие по M/Esc не вызывает паузу.

## Сохранения и контент

Сохраняем appId `io.verdant.voxel`, origin `verdant://app` и ключ `verdant-world-v1`: новый релиз не должен сбрасывать мир. Сохранения старой браузерной игры автоматически в Electron не переносятся.

Добавленная владельцем музыка `public/audio/relax.mp3` включается в Windows-сборку. Она не помещается в PROJECT.zip. Отдельный архив TEXTURES_1K содержит 14 PNG; музыка из источников хранится отдельно. Стандартное окно громкости и N остаются доступными.

Пакетная сборка и тесты не заменяют визуальную проверку WebGPU или проверку установки обновления на компьютере пользователя. Не считать такую проверку выполненной лишь по зелёному GitHub Actions.
