# VERDANT v0.1.10007

Воксельная песочница на Three.js / WebGPU / Electron. Карта минимум 2×2 км, Y от −1000 до +50 м.

## Обновление
Основной способ — автообновление установленного Electron из GitHub Releases `Dmitrynest2012/VERDANT`. Первая проверка через 9 секунд после запуска, затем каждые 30 минут. Приложение скачивает новый релиз и предлагает перезапуск. Раздельные ZIP исходников и 1K-контента — резерв и вариант для VS Code, а не замена публикации. Выпуск завершён только после Windows CI и проверки Release API.

## Сохранения
Новый мир создаётся в отдельном именованном слоте без window.confirm/prompt. Название и необязательный seed задаются в форме. Слоты доступны на стартовом экране, в паузе и по F8. F5 записывает текущий слот. Есть «Сохранить как», загрузка, переименование, удаление неактивного слота, предыдущий снимок, импорт/экспорт `.verdant.json`. До 100 слотов; снимок/импорт до 24 МиБ, с учётом доступной квоты. Все миры локальные, не отправляются в GitHub.

Прежний мир из localStorage переносится как «Мой прежний мир». Его рельеф НЕ меняется. Естественные озёра появляются в новых мирах генератора 2; старые постройки не затапливаются. Текущий слот сохраняется перед сменой мира и закрытием/обновлением Electron. Экспортируйте важные миры для независимой резервной копии.

## Вода и управление
WASD — ходьба, Shift — бег, Space — прыжок, Ctrl — присесть, E — инвентарь, F — фонарик, M — карта, N — музыка, F12 — отдельные DevTools.

В воде WASD учитывает направление взгляда. Space — всплывать и выбираться на берег, Ctrl — погружаться, Shift — ускорять плавание. Стены и дно остаются твёрдыми. Здоровье/утопление пока не вводились.

Ведро находится на панели нового мира; в прежний мир добавляется ведро воды один раз при наличии места. ПКМ пустым ведром по источнику — набрать; наполненным по грани — вылить. Источник и потоки не добываются буром. Твёрдый блок вытесняет воду из своей клетки. Первый водоём нового мира расположен около X=48, Z=−32.

## Графика воды
Общая волновая фаза, преломление видимой сцены через WebGPU/TSL, Fresnel, блики и приближённое отражение неба. Это не трассировка отражений объектов за камерой. Настройка «Графика воды» отключает преломление на слабых GPU. Под водой — сине-зелёная дымка и ограниченная видимость. Новых тяжёлых текстур для воды нет.

## VS Code и проверки
`npm install`, `npm run dev` запускают Vite + Electron. `npm run dev:browser` — браузерный режим. `npm test` — модульные проверки. Windows CI после Vite build запускает Chromium smoke интерфейса, IndexedDB и плавания; его успешное выполнение обязательно перед установщиком/публикацией. Тест на программном GPU не измеряет FPS пользовательской видеокарты.

## Музыка
Добавленный владельцем `public/audio/relax.mp3` сохранён в репозитории и включается в приложение. В маленький ZIP исходников и архив PNG музыка не входит; пользовательские файлы не удаляются. Лицензия трека отдельно не подтверждалась.
