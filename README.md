# VERDANT 🌿

Воксельная песочница на JavaScript / Three.js / WebGPU с настольным режимом Electron.

## Канал разработки

Этот репозиторий создан для публикации исходников и проверенных сборок игры VERDANT. Разработка ведётся с пошаговой версификацией `0.1.10005`, `0.1.10006` и т. д. Архив исходников и архив 1K-текстур — **раздельные**.

## Безопасные обновления

- Источник обновлений: **только** `Dmitrynest2012/VERDANT`.
- Коммит исходников **не равен** опубликованному релизу.
- Приложение получает обновление только после публикации двух соответствующих архивов и контрольных сумм SHA-256.
- Перед применением — проверка версии, целостности, тестирование и резервное копирование с возможностью отката.
- Личные настройки, сохранения, пользовательская музыка и файлы не удаляются.
- При отсутствии новой версии приложение работает без подключения к интернету.

**Статус:** репозиторий создан; первоначальная выгрузка исходников и настройка автоматических релизов ещё выполняются. Не следует считать содержимое данного README готовой игровой сборкой.

Дальнейшая документация проекта располагается в `docs/` после первоначальной публикации исходников.
