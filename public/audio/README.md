# Музыка VERDANT v0.1.10006

Пользователь добавил `public/audio/relax.mp3` в GitHub. Этот файл сохраняется при коммитах исходников и попадает в собранное приложение через Vite `public/`.

Приоритет: `relax.mp3`, `music.mp3`, `verdant.mp3`, `ambient.mp3`, `track.mp3`, `relax.ogg`, `music.ogg` в папке `public/audio/`. Включение и выключение — N; громкость — в меню. Карта использует M.

MP3 не входит в маленький PROJECT.zip и в архив PNG TEXTURES_1K.zip. При запуске из исходников пользовательский аудиофайл хранится отдельно. В установленном Electron используется версия аудио, включённая в конкретный релиз; простая загрузка файла в GitHub без нового Windows-релиза уже установленное приложение не изменяет.

Музыка предоставлена владельцем проекта. Не объявлять её CC0 или свободной для перераспространения без подтверждения лицензии. Не менять и не удалять пользовательскую музыку при обновлении исходников.
