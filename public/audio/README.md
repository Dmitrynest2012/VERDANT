# Фоновая расслабляющая музыка

Создайте путь **`public/audio/relax.mp3`**, именно с таким именем и расширением. Код проекта не содержит лицензированной музыки.

В браузере откройте игру, нажмите «Войти в мир» — после этого пользовательского клика игра автоматически попробует включить найденную музыку. **M** — включение/выключение вручную. В `Esc → Громкость музыки` регулируется уровень, а ниже показан статус обнаружения MP3 или ошибка воспроизведения.

Если нет звука: проверьте, что файл не `relax.mp3.mp3`, не лежит в `public/audio/audio/`, звук вкладки браузера не выключен, ползунок громкости больше 0%, MP3 кодируется в совместимом формате и не воспроизводится другая музыка поверх. Проверка файла делается в момент загрузки страницы и при повторном нажатии M.
