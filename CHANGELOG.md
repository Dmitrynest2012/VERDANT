# VERDANT — CHANGELOG

## 0.1.10005 — карта, Electron и GitHub
- Исправлена ориентация текстур боковых граней травы без отключения вариации UV сверху.
- Добавлена карта на M с масштабами 200, 400, 800, 1600 метров и плавным зумом.
- Закрытие карты через M/Escape возвращает управление без открытия паузы.
- Добавлен Electron с F12 (отдельные DevTools) и Windows NSIS-конфигурация.
- Добавлен GitHub Release updater для разработческого режима и автообновление установленного Electron.
- Подготовлена публикация Windows Releases с проверкой тестов и разделением ZIP.


## 0.1.10004 — исправление запуска и автообновления
- Повторно выпущены архивы v0.1.10004 с исправленными версиями в `index.html`, `src/main.js` и README текстурного набора. Теперь сборку блокирует тест согласованности версии, и ZIP проверяются отдельно до выдачи.
- **Исправлен критический сбой** `TypeError: ui.setGI is not a function`: в UI восстановлены методы `setGI`, `setMusic`, `setMusicStatus`.
- Добавлено тестирование полного контракта UI: проверка всех вызовов `ui.method()` из `main.js`.
- `npm run dev` теперь запускает одновременно монитор новых ZIP и Vite; отдельная команда `npm run dev:server` оставлена только для внутреннего процесса/отладки.
- Совместимость со старым монитором: после его установки 0.1.10004 вызов `npm run dev` запускает только Vite, пока старый монитор ещё работает.
- Обновлятор ожидает ОБА ZIP одной версии и не устанавливает частичную поставку.
- Добавлена диагностика `npm run update:status`: проверяет версию, папку Downloads, активность наблюдателя и имена ZIP.
- Исправлена рассинхронизация `state.json` и `package.json` после ручной распаковки исходников: текстуры новой версии теперь устанавливаются нормально.
- Сохранены пользовательская музыка, сохранения, раздельная поставка графики и проектных файлов.
- Уточнены правила в `.md`, включая обязательную проверку UI-контракта и правильную последовательность обновления.
