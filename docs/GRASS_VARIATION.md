# GRASS_VARIATION — канон с 0.1.10008

Верхняя трава использует MeshStandardNodeMaterial с общей непрерывной мировой проекцией. Два масштаба(2.4 и6.7м) и поворот второго слоя используют одну существующую grass_top и соответствующую normal map. Склоны нормалей поворачиваются согласованно. normalStrength сохраняется.

Нельзя возвращать независимые повороты UV по блокам или кластерам2×2 для верхней травы: такая схема создаёт несовместимые края. Цветовая макровариация и вершинное AO остаются плавными. Боковой дерн всегда направлен вверх; ступенчатая форма мира не сглаживается. Дальний LOD использует тот же материал. Новые PNG не требуются. Проверки и ограничения: RENDERING_REGRESSIONS.md.
