# GRASS_VARIATION

Чтобы трава не выглядела повторяющейся, но и не давала видимых стыков между блоками, используем три правила:
1. плавная крупномасштабная цветовая вариация с очень малой амплитудой;
2. UV-ориентация не по каждому метру, а по 2×2 м кластерам;
3. изменение должно быть мягким и не создавать сетку на плоском ландшафте.
