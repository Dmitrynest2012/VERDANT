# TECH_RULES

- Хранение мира — процедурная база + разреженные правки.
- Физика персонажа не зависит от LOD-плиток.
- Дальний рендер не должен влиять на корректность коллизий.
- Любые новые глубинные блоки добавляются так, чтобы старые сохранения продолжали читаться.
- Если в графике появляются screen-space эффекты, они не должны привязываться к центру экрана ошибочно.


## Точка входа и UI-контракт

`UI` — обязательный API для `main.js`. Методы `setGI()`, `setMusic()`, `setMusicStatus()` и другие вызываемые методы проверяются регрессионным тестом. Добавление вызова UI без реализации метода — блокирующий дефект.

## Автообновление

- `npm run dev` вызывает `scripts/dev-entry.mjs`.
- `dev-entry` начинает `auto-update.mjs`, когда нет работающего наблюдателя.
- Если уже работает монитор старой версии, `dev-entry` запускает только Vite: это предотвращает рекурсивный запуск второго наблюдателя при самообновлении старых установок.
- `auto-update.mjs` сам запускает дочерний сервер через `npm run dev:server` и не должен вызывать команду `npm run dev`.
- `npm run update:status` — диагностика без изменений файлов и без запуска Vite.
- Установка ZIP атомарная по управляемым файлам; пользовательская музыка и файлы вне манифеста сохраняются.

- Если вручную распакован проектный ZIP и `package.json` новее `.verdant-update/state.json`, версия установленной игры считается по `package.json`, иначе текстурный ZIP нельзя было бы применить.
