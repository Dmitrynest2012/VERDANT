# CURRENT_TASKS

## 0.1.10007
Реализованы именованные слоты, миграция прежнего мира, создание нового мира без удаления старого, резерв/импорт/экспорт, ожидание сохранения Electron, поверхностные чаши, источники/потоки/ведро, WebGPU-материал воды и плавание.

## Обязательные проверки до объявления релиза
npm test; Vite build + postbuild Chromium smoke (реальные IndexedDB и интерфейс/плавание/материал); NSIS; verify-release; verify-desktop-release; публикация всех активов и проверка Release API. Зелёный CI не доказывает установку обновления на компьютере пользователя.

## Ограничения, которые не скрывать
Старые миры сохраняют генератор1 без природных озёр. Нет waterlogging, точной гидродинамики, горизонтального переноса пловца течением, утопления/здоровья, рек/океанов/магмы. Отражение неба приблизительное. Не все прежние запросы графики завершены: бур остаётся HUD/CSS, облака — спрайтовые. Полировка их полноценной3D-графики — отдельная задача, не выдавать её за выполненную данным релизом.
