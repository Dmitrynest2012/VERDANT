## Ручная проверка на Windows
1. `npm run dev` запускает Vite и монитор; при старте нет TypeError.
2. В меню можно включать/выключать SSGI; музыка без MP3 выводит понятный статус.
3. `npm run update:status` показывает путь загрузок и состояние монитора.
4. Поместить пару ZIP следующей версии — увидеть остановку, тесты, сборку и перезапуск Vite.
5. Убедиться в сохранности пользовательского MP3, сохранений и текстур.
