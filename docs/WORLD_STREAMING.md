# WORLD_STREAMING

## Канон по размерам мира
- Минимальный размер карты по горизонтали: **2×2 км**.
- Текущий допустимый диапазон X/Z: **[-1000; +999]**.
- Текущая глубина мира: **до -1000 м**.
- Верхняя практическая граница пока: **+50 м**.

## Канон по глубине
Глубина хранится не сплошным массивом, а через вертикальные секции `16×16×16`. Это обязательно для будущих миров с глубиной -500 м, -1000 м и ниже.

### Природные слои сверху вниз
1. `GRASS` — верхний блок поверхности.
2. `DIRT` — верхняя земля под дерном.
3. `ROCKY_DIRT` — земля с редкими камнями.
4. `COMPACT_EARTH` — плотная земля.
5. `SHALE` — сланцевая порода.
6. `DEEP_STONE` — глубинная порода.

### Принцип генерации
Слой выбирается не по абсолютной высоте `Y`, а по **глубине относительно локальной поверхности**. Это правило обязательное: оно позволяет одинаково правильно работать на холмах, в низинах и в будущих больших мирах.

## LOD
- Ближняя зона: полноценные воксели, физика, копание, дропы.
- Дальняя зона: облегчённый heightfield LOD.
- Между LOD-плитками обязательны скрывающие `skirt`-полосы против белых/синих щелей.
