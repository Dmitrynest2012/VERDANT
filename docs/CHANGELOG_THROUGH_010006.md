# VERDANT — CHANGELOG

## 0.1.10006 — публикация обновления через GitHub
- Изменения ранее выданного ZIP перенесены в репозиторий с сохранением добавленного владельцем `public/audio/relax.mp3`.
- Подготавливается полный Windows-релиз: EXE, latest.yml, blockmap, два резервных ZIP и контрольные суммы.
- Добавлена проверка согласованности версии, имени EXE, размера, SHA512 и встроенного GitHub-источника обновлений.
- Публикация выполняется только после тестов и сборки; до окончания загрузки файлов релиз остаётся черновиком.
- Закреплено: выдача ZIP в чате не заменяет доставку обновления в установленный Electron.
- Из предыдущего архива 0.1.10006: изменения LOD-материала и маски, многослойные облачные спрайты, новые ореолы солнца, прогрессивная карта и экранный HUD-бур с анимацией. Это не подтверждение устранения всех графических дефектов; бур в этой версии ещё не является геометрической 3D-моделью Three.js.
- Поиск музыки расширен на дополнительные имена MP3/OGG; загруженный владельцем relax.mp3 не переименовывается.

## 0.1.10005 — карта, Electron и GitHub
- Исправлена ориентация текстур боковых граней травы без отключения вариации UV сверху.
- Добавлена карта на M с масштабами 200, 400, 800, 1600 метров и плавным зумом.
- Закрытие карты через M/Escape возвращает управление без открытия паузы.
- Добавлен Electron с F12 (отдельные DevTools) и Windows NSIS-конфигурация.
- Добавлен GitHub Release updater для разработческого режима и автообновление установленного Electron.
- Подготовлена публикация Windows Releases с проверкой тестов и разделением ZIP.

## 0.1.10004 — исправление запуска и автообновления
- Исправлены версии в index.html, src/main.js и README текстур.
- Восстановлены UI.setGI, UI.setMusic и UI.setMusicStatus; добавлен тест UI-контракта.
- npm run dev запускает монитор ZIP; внутренний Vite не запускает второй монитор.
- Обновлятор ожидает оба ZIP одной версии; добавлена команда update:status.
- Исправлена рассинхронизация state.json и package.json после ручной распаковки.
- Пользовательская музыка, сохранения и посторонние файлы сохраняются.
